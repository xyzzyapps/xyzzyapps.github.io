# xyzzyapps.github.io

Official portfolio and research index for **[Xyzzy Apps](https://xyzzyapps.github.io/)** (`@xyzzyapps`).

This GitHub Pages website catalogues and categorizes 77 open-source repositories spanning:
- **Languages & Compilers**: Prefix concatenative Lisps, Smalltalk/Tcl hybrids, English automation shells, C transpilers.
- **Literate Programming & Code Translation**: Noweb Markdown wrappers, topologic explain-order compilation, C-to-English decoders.
- **Systems & DevTools**: NASM assembly macros, C static analyzers, unconventional TUI/GUI editors.
- **Generative Audio & Creative Media**: DAW MIDI inference engines, algorithmic hardgroove techno, Pure Data DSP.
- **Simulations & Games**: Live-patchable desktop arthropods, insect neuro-simulations, Three.js shaders.
- **Web & Runtimes**: Single-file component compilers, Go PHP-style templating, mobile TUIs.

## Features
- **Instant Search & Filtering**: Real-time keyword search across project names, descriptions, tags, and languages.
- **Taxonomy Categories**: Curated tabs for Compilers, Literate Code, Systems, Audio/DSP, Simulations, and Web Runtimes.
- **Live Demo Launcher**: Direct launch buttons for interactive browser-based demos.
- **Fast & Responsive**: Lightweight, zero external runtime framework dependencies, self-contained.
- **Dark / Light Modes**: Sleek cyberpunk dark mode with persistent user preference.
- **1-Click Git Clone**: Instant clipboard copy of clone commands.
